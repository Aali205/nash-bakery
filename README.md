# NASH — Artisanal Bakery · Damascus · Est. 2018

An animated, bilingual (English / العربية) website for NASH Artisanal Bakery.

- Cinematic intro: espresso pour, N·A·S·H letter drop, bean burst, iris reveal
- Real-time 3D espresso cup (Three.js), procedurally modelled: crema shader, steam and floating coffee beans
- Scroll choreography with GSAP ScrollTrigger + Lenis smooth scrolling
- Damascene rose-petal particles, horizontal signatures gallery, filterable menu, midnight clock
- Live "open now" status using Damascus time

## Run locally

```bash
npm start   # http://localhost:5173
```

No build step and no dependencies. Libraries load from jsDelivr.
